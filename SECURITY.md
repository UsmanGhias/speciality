# Security Policy

## Supported versions

Security fixes are considered for the latest published Odoo 18 module version on the default branch of this repository.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities that could expose data or credentials.

Instead, contact the maintainer privately via GitHub security advisories for this repository (if enabled) or by contacting the repository owner through GitHub.

Include:

- affected module version
- Odoo version
- reproduction steps
- impact assessment
- whether credentials or personal data are involved

## Out of scope

- Issues that only exist because no open-source license is declared
- Feature requests unrelated to security
- Reports that require rewriting historical commits

## Maintainer response goals

- Acknowledge reports as soon as practical
- Confirm whether the issue is valid
- Coordinate a fix on a feature branch before merging to the default branch
